# Security policy

This repository publishes a static, offline-capable guide and downloadable
templates. It does not operate an account service or collect credentials.
Its build and release tools still process files and dependencies; vulnerabilities
in those tools or in the downloadable artifacts are relevant reports.

## Reporting a vulnerability

When GitHub private vulnerability reporting is available for this repository,
use [Report a vulnerability](https://github.com/MJmuhammadjihad/AI-ML-Engineering-Portfolio/security/advisories/new).
Include the affected revision or download, reproduction steps, expected and
observed behavior, and impact. Remove secrets and personal information from
examples.

If that option is unavailable, use a private contact method listed on the
[maintainer's profile](https://github.com/MJmuhammadjihad). If none is listed,
open an issue asking for a private reporting channel without including exploit
details or sensitive data. Please allow private discussion before publicly
disclosing a working exploit.

## Supported versions

Fixes are developed on the default branch. Older downloadable releases may
remain available and are not maintained as separate supported versions.
This is a personal project with no guaranteed response time or security audit.
General content corrections and broken links can use the regular issue forms.
