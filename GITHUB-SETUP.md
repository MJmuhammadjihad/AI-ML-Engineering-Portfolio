# Repository About details

The reviewed description, website and topic list are in [repository-details.json](repository-details.json). These settings live in GitHub’s repository database; committing a README or this file does not apply them.

Use the repository’s About gear, paste the values and click **Save**. For a verified command-line update of this repository and The Long View together, use the [owner-run helper and instructions](https://github.com/MJmuhammadjihad/the-long-view/blob/main/docs/PUBLISHING.md#apply-missing-about-fields-with-verification).

The helper uses your existing GitHub CLI login, preserves nonempty descriptions and websites, retains existing topics, and verifies the result. It does not read or print token values. A connection may be able to push files yet lack repository Administration permission; a 403 response requires an appropriately authorized owner session or the GitHub settings interface.

The existing [maintainer guide](docs/MAINTAINER-GROWTH.md#one-time-owner-settings) explains the separate social-preview setting. The supplied image is [assets/social-preview.png](assets/social-preview.png).
