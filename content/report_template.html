A plan you can use

Build your portfolio plan.

Choose a direction, set a sustainable study budget, and track the evidence you can demonstrate. Each step links to its full project brief.

Start with the foundation. Build the two complementary flagships in an order that fits your eligible target roles, improve one system’s reliability, and prepare a contribution and case study.

The guide’s default allowance is 24 weeks at 36 study hours a week. Adjust the calendar to your circumstances and move on when you can demonstrate the gate.

Explore both: build the forecasting project first to practice data and evaluation before adding generated answers.

  1. 01

    Own a small Python/data tool

    Gate: add a CSV validation rule and a regression test, debug a malformed input, and explain the code independently. Build the software/data prerequisites before either flagship.

  2. 02

    Demand Replay · forecasting

    Gate: reproduce a baseline comparison, defend the prediction-time boundary, and explain leakage checks and observed errors. Requires the software/data foundation and basic regression/evaluation.

  3. 03

    Evidence Desk · grounded answers

    Gate: reproduce retrieval and answerability evaluations, show citations and abstention, and explain a remaining failure. Requires API, text-processing and evaluation fundamentals.

  4. 04

    Make one flagship recoverable

    Gate: demonstrate bounded failures, useful logs and a rollback drill on a working flagship. Report measured local conditions and monitoring limits.

  5. 05

    Contribute, explain and apply

    Gate: show a useful contribution with its actual status, a reproducible case study, and evidence matched to eligible roles. Practice an unfamiliar code change independently.
