# Portfolio execution templates

These are **unfilled working templates**, not records of completed projects, evaluations, contributions, or applications. Replace every `[bracketed field]` with verified information, or say `not measured`, `not implemented`, or `unknown`. Never publish a template's example wording as a claim about your work.

Start with the small CSV checker. Use the flagship templates only when their prerequisites are understood. The plan in `milestones.csv` is a 24-week first pass at six focused hours on six days per week; learning speed and employment outcomes are not guaranteed. Move the dates when an evidence gate is unmet.

| File | Use |
| --- | --- |
| `project-readme.md` | Help a reviewer understand, run, and assess one actual project. |
| `evaluation-plan-and-results.md` | Declare the protocol before tuning; append measured results after the run. |
| `experiment-log.md` | Keep decisions tied to code, configuration, and actual output. |
| `case-study.md` | Explain one consequential engineering choice and its evidence. |
| `publishing-checklist-and-posts.md` | Prepare truthful GitHub, LinkedIn, and demonstration assets. |
| `role-application-tracker.csv` | Separate eligibility, required capability, preferred criteria, and evidence. |
| `milestones.csv` | Schedule the recommended work and track evidence gates. |
| `results.csv` | Store one measured metric/slice per row; the file initially contains only headers. |

The application tracker initially contains only headers. Put exact posting text in requirement fields, preserve its URL and retrieval date, and mark unstated conditions as unknown. “Remote” does not automatically mean worldwide. Keep your private application notes and personal information out of public repositories.

For a forecast, preserve the prediction-time information boundary. For the documentation assistant, preserve the versioned corpus, topic-grouped splits, and answerability labels. For reliability work, label local load tests and injected failures as controlled drills. Submitted, reviewed, and merged contributions are different states.

Keep a private draft until placeholders are resolved. These documents do not perform public posting, contact employers, or submit applications.
